ABOUT · 关于本项目

关于 About

把「碳材料超级电容器三维导电网络」的文献，做成一张可导航、可检索、可统计的知识网。

01项目理念

三维导电网络是超级电容器电极从“材料堆砌”走向“结构设计”的核心范式：让电子有连续骨架可走、 让离子有贯通孔道可进。相关研究横跨材料、化学、器件与工程，文献高度分散。 CarbonNet 以脉络树建立体系认知、以三层关系图贯通材料—策略—文献、 以文献库与数据面板提供检索与全景统计，并以BYOK AI 助手提供按需解读。

02数据管线

文献元数据来自 OpenAlex ↗（CC0 开放数据）。 抓取脚本 scripts/fetch-openalex.js 多路检索后按主题门控去重， 合并 10 篇人工遴选经典文献（附中文解读），输出 data/papers.js。 GitHub Actions 每周一自动抓取、先 fetch + rebase 再推送，站点无需构建、自动更新。

03AI 助手与隐私（BYOK）

AI 文献助手采用 Bring Your Own Key 模式：

  • API 密钥只保存在你浏览器的 localStorage，绝不进入代码仓库、绝不发给本站服务器；
  • 浏览器直连硅基流动 api.siliconflow.cn，不经任何中转；
  • 本静态站不采集任何数据：无统计脚本、无 Cookie、无第三方请求；
  • 未配置密钥时，其余所有功能照常可用。

04工程铁律

  1. 缓存版本：每次改动 CSS/JS，所有引用 ?v=N 统一加 1，杜绝浏览器旧缓存。
  2. 动画退役：入场动画 animationend 后置 animation:none !important；绝不在 :hover 上移除动画（悬停只用 transition），杜绝卡片闪没。
  3. 力导向手势：pointerdown/up/move 期间绝不 setOption（布局冻结、操作排队）；点击导航 = click 事件 + pointerup 位移 <6px 兜底，拖拽（>6px）不导航。
  4. 防 XSS：文献数据渲染一律 textContent，绝不拼 innerHTML。
  5. BYOK：密钥仅存 localStorage，直连硅基流动，不进仓库、不引第三方脚本。
  6. 零第三方请求：ECharts 与字体本地打包，运行时只访问本站文件。
  7. 提交纪律：push 前先 git fetch + rebase origin/main。
  8. UTF-8 编码纪律：所有文件一律 UTF-8 无 BOM；编辑/校验禁用 GBK 默认编码工具（如 PowerShell 5.1 的 Get-Content 会误读中文），提交前自查无乱码。

05技术栈

  • 原生 HTML / CSS / JS，无构建步骤，直接部署 GitHub Pages；
  • ECharts 5.6 本地 vendored（assets/vendor/echarts/），图表颜色从 CSS 令牌读取，改令牌即全站换肤；
  • Space Grotesk（标题/数字）+ DM Mono（点缀）本地打包，无网络字体；
  • 深色/浅色双主题 + 弹簧缓动 + 景深模糊渐清 + 错峰入场，全程尊重 prefers-reduced-motion。
