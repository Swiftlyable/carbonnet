ABOUT

关于 CarbonNet 碳网图谱

一个面向「碳材料超级电容器三维导电网络」方向的文献知识站： 静态、零构建、零第三方运行时请求，数据每周自动更新。

项目定位

以 OpenAlex 文献元数据为骨架，把散落的论文组织成三层知识结构—— 材料体系（石墨烯、碳纳米管、生物质碳……）、构筑策略（模板法、自组装、3D 打印……） 与器件性能（能量密度、循环稳定性……），帮助研究者快速定位脉络、经典与前沿。

站内所有图表颜色与界面颜色共用同一批 CSS 设计令牌，改一个变量即全站换肤。

数据来源与更新

  • 文献元数据来自 OpenAlex（CC0 许可，可自由再分发）。
  • GitHub Actions 每周一 02:00 UTC 自动抓取并提交更新。
  • 数据由 scripts/fetch-data.mjs 生成（零依赖 Node 脚本）。
  • —

技术栈

原生 HTML/CSS/JS ECharts 6（本地 vendored） Space Grotesk DM Mono GitHub Pages GitHub Actions OpenAlex API

无构建步骤、无 CDN、无第三方脚本；字体与图表库全部本地打包， 页面加载零第三方请求。

AI 助手与隐私

AI 助手采用 BYOK（自带密钥）：你填写的硅基流动 API Key 只保存在 你自己浏览器的 localStorage 中，请求由浏览器直连 api.siliconflow.cn，本站不存储、不上传、不中转任何密钥或对话内容。

AI 生成内容（如中文摘要翻译）仅供参考，请以原文为准。
